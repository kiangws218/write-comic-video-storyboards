# Dialogue and character performance — 2.8.2

本模块维护人物表演方法、声音归属与台词承载、真实计时。原镜／全文锁定、邻镜差异和节点到达由 [core-authoring.md](core-authoring.md) 唯一维护；不另设证据准入。首次人物写作前完整读 [acting-calibration.md](acting-calibration.md)，学组织方式，不照搬动作／人物／道具。导演阶段另读 [director-expansion.md](director-expansion.md)。

共享人物主档的维护、稳定代称与开篇上色提示词见 [character-registry.md](character-registry.md)。本模块只维护表演方法，不另建性格真值副本。

## 角色性格先于通用动作

从用户确认及既有角色记录确定 profile，应用于姿态、任务、启动速度、动作幅度、视线、对人距离、停顿和声音。人物参考图只证明设计，不证明性格。用户已确认的本项目基准：

| 角色 | 基准 | 可选表现与限制 |
|---|---|---|
| 春子 | 三无、克制 | 稳定主姿态、少而明确的注意力变化、任务中断与回应时机；声音与表情克制，身体仍会行动／受力。不要每句歪头点头或夸张笑怒。 |
| 青 | 活泼阳光 | 较主动接近与回应、开放姿态、明快身体节奏；严肃或危险时自然变化，不永远蹦跳大笑。 |
| 董白 | 高傲自负 | 从容占据空间、判断性的注视、控制感与短暂停留，爆发可与克制形成反差；不默认狂笑怒吼，也不抹掉原作明确压力／反射。 |

这些是选择依据，不是动作模板。相同挑衅下，春子可以任务短停再看，青可更快转向主动回应，董白可让对方等一拍再行动；实际选择由本场关系、刺激、源节点决定。原作明确表情／生理反射不能被性格标签抹掉，不凭一句粗话推断更强怒意或隐藏动机。

## 先构思完整表演，再写表演卡与姿势细节

从人物正在进行的行动、姿态或接触中构思完整演出：他想维持、打断、推动、回避还是等待什么，对方的反应如何改变他的下一步。先定可读的主要行为、主姿态及其发展，再让表情、视线、手部和次级运动参与。丰富度来自有作用的互动、参与程度的变化和层次分明的节奏，不是把唇动、指尖或关节调整拆成许多步骤。

“当下行动／状态→刺激→有选择的应对→任务或关系的变化／延续→当前结果”是理解工具，不是每镜必走的流程。主要行为在正文实际发生，节点间自然抵达下一原镜。不为制造个性另塞无关道具、差事或隐藏动机；没有具体任务时，清楚表情、注意力变化或有作用的静止也能成立。

### 以交流关系组织演出

学习《学园》校准中情境、身体和对手反应相互牵动的组织方式；以下按当前人物与处境选择，不拼接成手势库：

- 一方积极、另一方冷淡或忙碌时，写出回应怎样影响发起者后续行为；多人有不同的参与程度，不全员同步或默认所有听者冻结，也不要求每个背景人都动。
- 关心和询问从朝向、距离和参与程度发展：怎样交出注意、试探、等待或追问。疑问句不自动歪头，邀请、解释或无奈不自动摊手。
- 被打断或突然理解时，原有行动可以停、慢下来或继续；主体与衣物、发束的运动按实际先后或交叠组织，不统一套“迟半拍”。
- 拒绝、接受或犹豫改变参与方式，结果带入下一拍；听者也可影响说话人的节奏，但不能响应未听见的内心话。

### 写成可读、连贯而有幅度的芝居

按实际画幅选可见表演：头肩或中景可由头部朝向、肩背和躯干关系共同承载变化，宽景可由全身行为与剪影承载，面部特写可由清楚的图形表情成立。写清主要行为从哪里开始、怎样变化、到达什么状态；视线与转头分开，不用抽象“重心变化”代替可见结果，也不要求每镜位移。

用自然完整的动作叙述连接态度和行为。有依据的“困惑地”“有些不耐烦”“神情放松”可直接使用，并由表情、动作或反应承载；不把正文写成眼睑、嘴角、指尖、肩部调整的拼盘。技术细节和精确幅度只在影响执行时写，不为简短删去必要表演。

短镜也可有《学园》式并行表演：一人的主要行为、另一人的回应和衣物／发束变化可以交叠，不全部串行排队。幅度与速度在当前景别中须可读，不把变化一律缩成“微微／极小／轻轻”。生活化来自性格、处境、惯性和交流逻辑，不等于只有小动作或取消二维夸张；具体二维表现见导演与执行模块。

次级运动依附主行为，不机械在镜尾追加眨眼、捏指、回正或发丝回弹。镜尾可继续行动、维持有效姿态或保留变化后的态度；手势的交流作用结束后自然收束，不能只为连续性长期悬置。原格已有姿态与明确表情仍须保留，跨镜延续朝向、注意、持物、接触和情绪余势，返回不重演同一变化。

## 原句与切镜

逐泡确认原文／尾部／声音归属，分别登记对白、独白和旁白。问→答、指责→否认、打断、揭示→反应的语义顺序保留；机位可不同于说话人。完整等值翻译在第二次精读核对后冻结，第三轮不改词、不添喊话。

先确定整段如何影响人物，再安排说话人、听者、关系、物品、环境与返回。长话可以画外连续，镜头不必每镜有台词；插入不能拿未来原镜提前揭晓来顶替。返回原机位显示当前状态，不回到切走前的起点。

正式对白一条一行，例如 `角色（画外音）：“实际锁定片段”（原声线，克制语气）。` 独白在角色后写 `（内心）`，旁白写 `（旁白）`。不在正式稿保留示例占位。段落拼回与锁定全文一致。需要按词同步动作时用 `说到「本镜实际原句的准确片段」时`，或一般的开口前／重音／句末节点；这只定位行为，不新增说话。

二十一／二十八／四十二字、分句数与多说话人用于安排审查和计时，不是手势／镜头数量规则。长镜有足够任务、参与或有效停留可以成立；单靠延时、缩台词、通用合并理由不能通过演出审查。

## 沉默与实际时间

允许句前、句中自然边界、句后明确写 `（沉默2秒）`，不改原句标点来凑停顿。沉默期间世界可继续，环境、呼吸、拟音不自动静音。整镜无话写“无台词”，可以纯动作、情绪、环境或节奏演出。

镜头总时长=串行前奏+并行层的最长时间+串行后奏。句前2秒+发声5秒+句后1秒，动作并行在发声内，则共8秒。每个明确沉默有对应实际时间，不重算同一时间，也不把说话和所有动作一律算整镜同时。

喝水／进食时区分近唇准备、封闭口部接触和吞咽。本人完整发声不能占用封杯／吞咽时间；他人画外回答可以与之并行。一次喝水不用为填时长再喝一次。

日语约六个有效字每秒及标点附加只作预估提醒，实际录音／动态分镜优先。第三轮可重排第二轮时长，最终十五秒限制由 core 管理，不靠删台词解决。

## D/P/G 与表演卡

- D：多气泡／多声音、类型交错、长话或语义转折，需要完整声音顺序和承载计划。
- P：具体人物表演、任务／听者／关系的变化需要规划，包括短镜和无声镜。
- G：原格的身份／肢体／接触／透视仍有关键歧义，需要回图；新增角度本身不要求补证。

路由决定规划精力，不决定角色有没有权行动。中性／物品／环境镜不强制人为设卡，D/P/G 无动作配额。P 使用已有 opening / beats / coupling / landing、正文 details 和实际 intervals，不增加另一张卡。

opening 为当下任务、主姿态与关系；beats 为真正应对和发展；coupling 为如何影响任务／对方，不是重复来源许可；landing 为镜尾当前状态，不是必须停住。可只有一个有用节拍，也可以短镜内多层同时表演。卡先于正文，正文摘录事后用于核对实现，不能包住整段成稿就声称已规划。

## 眉形与表达连续性

先识别形状，再解释情绪。区分眉头／眉尾、内端抬起、全眉抬起、内端下压靠拢；八字眉不是笼统双眉升高，抬起与靠拢可同时存在。辨别眉、眼睑、发丝和阴影，区分透视／头倾与表达、固有形状与当前变化。

保留可见不对称；只露一边不伪报两边。在原作节点保留明确形状，节点之间可以导演表演。需要识别的细节仍不清才放大，不按每句制造眉跳。舒展不必变成直线，持续八字眉可以成立。表情在动作字段，摄影机负责其可见性，不写竞争指令。

## 实质演出复核

完成原作和连续性核对后，以 [acting-calibration.md](acting-calibration.md) 的《学园》原段与对应薄弱缩写检查实际正文。判断实际画面，不以动作合规、卡片齐全或理由充分代替演出质量：

- 能否直接读出主要行为、明确态度、过程、先后／交叠及当前结果？身体参与或表情在实际画幅中是否可见？
- 人物何时接收信息，怎样应对，如何影响任务与对方？整段参与是否有性格与情境差异，而非轮流说话、轮流做相同手势？
- 暂去口型、发丝和细微装饰后，主要行为、表情或节奏是否仍能承载这场戏？若接近原姿势配口型，须重构行为和互动，不能只换成摸杯、眨眼或捏指。
- 停留是否在准确时机产生等待、压力、尴尬或余韵？保留有效安静与克制，不把它修成忙乱，也不按动作数删薄丰富的短镜表演。

按整段交流与实际时长判断。连续小幅低头抬头、“说话—回正—等待”和通用手势，即使各有原因也可能生硬；要回到主要行为、表情、对手关系和节奏实际改写，不靠“符合性格”“来源允许”或因果标签辩护。上述是语义诊断，不设动作、手势、身体部位配额或新切镜门槛。

结论并入已有revision_audit／director_review，仅记受影响镜头、具体保留或重构的表演／互动及限制，不新增表或逐镜复述。已识别的主动作缺失、生硬或互动不足须改后交付；影响原作节点、构图或接触时按core局部回源。来源warnings、结构结果与演出判断分开报告；卡片和零结构错误不证明生动自然，未播放动态分镜就如实说明文字审查范围。
