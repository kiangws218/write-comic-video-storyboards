# 2.8.2 兼容与规则所有权

只在维护／兼容审计时读取，不是普通创作的隐藏规则。用户最新明确要求高于旧版本约定。保留同一 skill 标识，以 metadata 和台账 skill_version 分流。

- 已有无 skill_version 的 V3 台账继续走 legacy 检查，保留旧测试和旧交付，不静默改其含义。
- 新版仍是 V3，但须使用 2.8.2 来源／对白锁及最终导演审查格式。旧台账不能通过改版本号或自动填 pass 升级；回看实际原图并完成缺少工作。
- 总览、局部两次看图、按需分辨率、真实气泡归属、观察和推断分开、眉形／机位／视线、任务表演、串并行、颜色和六字段均继承。
- 全部原作画面节点及顺序必须保留；真正连续的相近原格可按core合为一个动画镜头，逐格映射阶段、状态与正文。不能把合镜误写成删格，也不能强制每个原格各切一次。
- 全文锁定替代旧“意思不变即可”。长话字数只是审查提醒，不能靠缩写或强制切数通过。
- 旧两项差异改为与最终紧邻前后各一项，不再比较非邻接下一源格。
- 旧动作／空间／造型证据准入、单格最多一个推断 A/C、单格所有权超时例外均不约束新版导演创作。证据不足只 warning，未知不等于错误；实际矛盾仍修正。
- 唯一规则位置：core 管不可变条件、差异／节点／连续性／字段；director 管整场创作方法；dialogue 管人物表演／声音与计时；ledger 管 JSON 存储。其他模块链接，不维护一套竞争准则。
- 标记与布尔值不能证明看图或审查；机械指纹只能绑定版本。手工发现的演出问题必须诚实报告，未看视频不声称成片验证。

分工修订：第二遍继续完整写原镜六字段、角色表演与基本计时；最终邻接、发声精确切分、分片和执行精修后移。第三遍创作不豁免原镜画面与表达保真，按第二遍快照及原图对照。
