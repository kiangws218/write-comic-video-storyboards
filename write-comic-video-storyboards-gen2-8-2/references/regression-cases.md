# 2.8.2 回归案例与成熟经验

维护／前向测试时读取；普通创作规则均由入口可达模块定义。本表继承有效视觉案例，替换与最新权限冲突的旧预期，不复制一套准入规则。合成单元测试不是实际图像审查。

| 情境 | 预期行为 |
|---|---|
| 新话有很多原格 | 有序分页总览只定地图；局部两次逐图精读，不从缩略图转录整话。 |
| 第二次精读只有首次笔记 | 重新看实际图再写；发现误读修正事实，不维护两份来源台账。 |
| 格式／编号修订 | 机械检查即可，不强制整话重读，不谎报新视觉审查。 |
| 窗口结束而场景未完 | 一至三格窗口不决定切镜／分片；暂存真实状态，完成段落再导演。 |
| 机位俯拍、人物向上看 | 分开机位／光轴与头眼方向；不误写仰拍。 |
| 只有一侧八字眉，另一侧被遮 | 保留可见内高外低和不对称，不把眼睑当眉、不补造隐藏眉的观察。 |
| 身份仅凭黑发相似 | 用明确设计特征和实际图核对；否则稳定描述名与不确定，不猜已确认姓名。 |
| 喝水者有问题、另一人回答 | 本人话先于封杯／吞咽，他人回复可画外并行；不新增一口填时间。 |
| 原格接触／结果，没有起手 | 在正确阶段保留原镜，允许设计完整过程；不直接绑视频首帧，不强制冻结。 |
| 前格已经举手或拥抱 | 延续真实状态，不因换镜／分片重复形成过程；可设计后续接触变化并自然抵达下一节点。 |
| 切听者再返回 | 画外时间继续，返回是此刻状态；不复演抬手、起身和情绪循环。 |
| 原格半脸来自格框 | 观察如实，动画可依完整人物参考补全；保留原镜视觉重点。 |
| 遮挡用于隐藏身份 | 保留揭晓时机，不借扩画提前暴露。 |
| 完整背面参考缺少漫画机位 | 完整人物参考支持造型，不要求逐面漫画证明。 |
| 连续相近原格是同一长镜头的阶段 | 允许合成一个实际动画镜头；逐格节点、状态、顺序和完整台词均有实际实现，不能只剩引用。 |
| 相似角色但不同反打／揭示／时间 | 保留镜头观察关系，不用通用合并理由抹去差异。 |
| 第20話_12_002只记正脸瞪眼 | 复核空中迎面冲势并落实动作，不把构图描述当动作理解；不将所有正面透视套成冲刺。 |
| 未识别角色每镜换代称或未定色 | 共享主档稳定ID与称呼，开篇统一上色提示；颜色设计与源事实分开。 |
| 一文件含两格／一格任意两裁图 | 前者独立登记真实两格；后者不制造两个源画面。 |
| 纯拟声格 | 原文和实际音义映射到真实镜头，不生成字形，不漏声音。 |
| 同句跨多个镜头 | 全文只出现一次，拼接逐字相等、归属／类型／顺序正确。 |
| 导演缩写／同义改词／新增喊话 | 全文锁定失败，不能以时长或气势豁免。 |
| 句前后沉默 | 明确计时、位置一致、不得与发声重叠；环境可以继续，不修改原句标点。 |
| 新镜是纯表演或环境余韵 | 允许独立成立，按内容、节奏、差异和节点到达审查，不强塞台词。 |
| 新增镜头只有一项真实差异 | 对最终前后两侧分别各有至少一项即可，不要求两项。 |
| 只比前镜或非邻接下一原格 | 不通过；按最终实际邻镜重新设计与记录。 |
| 返回机位和早先机位相同 | 不比较非邻接的旧机位；对实际前后镜检查，可成立。 |
| 眼神特写只改变景别 | 若重要判断真实可读，可算一项；仅微小焦距或标签变化不算。 |
| 新增镜头与下一原镜重复 | 重设计新增镜头或将有效动作写进保留原镜，不能删除原镜。 |
| 新侧面／路线／接触未在漫画画出 | 仅来源warning；设计连续空间与动作，不要求逐条消警签批。 |
| 首次关键动作段，路径可能误读 | 第一次精读后提交简明路径，用户明确确认再开始本段第二遍；这不限制确认路径内的导演创作。 |
| 辅助台账比正文还重 | compact状态增量、每切点一次差异、镜内表演卡；工具展开，不复制全文到复核表或重新通读派生产物。 |
| A→B 改为 A→X→Y→B | 保留源观察；旧连接失效，复查新连接、实际邻镜差异及真实受影响后续。 |
| 修改了时长／角色设定／镜尾 | 最终版本审查指纹失效，按真实范围复核；指纹不自动授予通过。 |
| 新攻防多于一个补间 | 允许完整编排，结果／伤势／能力不改，自然到达下一原节点。 |
| 背后高速跟随切正面 | 同一次运动继续，空间／速度／目标可读，不重复起跳／归零。 |
| 镜头内手势或摄影机持续变化 | 不要隐藏真实切镜；连续运镜不逐角度强制切镜或套差异。 |
| 十五秒装不下完整演出 | 合理分生成片段，每片不过限，不删原句原镜或压掉反应。 |
| 单格不足十五秒而场景需跨片 | 允许按最终动作／语义分段，不恢复旧单格所有权例外。 |
| 角色性格不同而手势循环相同 | 按任务、应对、姿态、节奏和语气重写，不能只改情绪形容词。 |
| 春子三无／青阳光／董白自负 | 克制不冻结、活泼不永远笑、自负不狂笑模板；具体原格反应仍保留。 |
| P卡有眼眨、指尖、头发但漏主事件 | 语义复核失败，恢复主动作／人物参与，不补同义词。 |
| 短镜多层并行动作 | 按真实串并行计时，可丰富；没有动词、关节数和手势配额。 |
| 长静止或固定机位 | 按人物、时机、画幅和节奏判断，可以成立，不自动缩短。 |
| 灰网点、空白或完全遮挡 | 分别判断材质明暗、实景补全／图形、真实遮挡，不用头发脸填背景。 |
| 彩色道具跨单色格 | 稳定参考底色；光照临时染色不永久改色，图形星光不自动变魔法。 |
| 新图形没有外部可视参考 | 允许诚实原创设计，只warning；不声称静帧证明运动或失败预览已看。 |
| 强击与效果 | 主动作可读，方向／材质／峰值衰减明确；不每击叠满震动、烟雾和闪光。 |
| 执行稿字数超预算 | 去重复细节或合理分片，不删原句原镜，不把所有镜头改成原镜角色。 |
| 机械零错误 | 分别报告还原、对白、连续性与演出；未播放动态分镜不宣称成片质量。 |
| 旧 V3 / 新2.8.2 / 未知版本 | 旧走旧检查、新用新版契约、未知版本拒绝；迁移不自动看图或填pass。 |

运行 `python -m unittest discover -s scripts -p "test_*.py"`。另用真实原图验证动作和长对白样段，记录实际范围、来源限制、人工判断与是否播放；程序无法证明艺术判断。

## 分工与原镜保护的专项回归

| 情形 | 预期 |
|---|---|
| 第二遍因减负只交动作清单，原镜六字段／表演留空 | 不合格，恢复成熟原镜完整写作；后移的是最终剪辑与执行计算。 |
| 第二遍局部特征齐全但整段主事件与因果不明 | 回图读通再写，用story_context串联，不另堆表单。 |
| 第三遍台词和源文件名保留，但主动作／观察关系消失 | 原镜保真失败，不能仅凭覆盖统计或同一剧情结果放行。 |
| 第三遍扩展原镜、改时长与适配页面裁切 | 允许，源节点内容与表达仍落实；不逐字冻结六字段。 |
| 新增镜头改变邻接／分片 | 最终重查实际邻接与计时，不让第二遍为暂定剪辑反复计算。 |

## 0.5秒与二维表现回归

- 0.5秒和2.5秒镜长经过渲染、原镜映射、对白区间检查和执行稿审计后不被截断；整数秒旧稿继续有效，0.3秒镜长及片段超限报错。
- 【可见动作】可使用连续的本镜时间段；留空、重叠、倒序、越界与终点不一致报错。简单动作自然语言无需时间表，段内“瞬间一张残影”不被误当成独立切镜。
- 金田系、作画感、Q弹、张力拉满等保留为可用表现提示；Q版或有意形变不被通用禁止变形覆盖。机器不按词频评判艺术质量。
- 继续使用一个compact台账；无新增动作阶段／曝光／风格切换数组，第二遍快照与原作／全文锁仍有效。原镜节点、性格和到达状态不能因夸张而丢失。

## 多人同格、长竖格与表演审查

- 同格A→B→C依次发言可用一条连续摇移承接，路径、停留、口型／画外音和原格关系须落实；不强迫每句话切镜，也不把不同原格无条件合镜。
- 长竖格优先上摇／下摇，检查起幅、途中关键内容、落幅和揭晓顺序；人物不被拉宽压短，原格纵向内容不因裁切丢失。替代方案记录在已有frame_adaptation，不增表。摇镜与机位升降分清。
- 表演审查对照《学园》的完整行为、互动与并行节奏；克制或静止可成立，不能用原姿势加口型／微动作代替整场演出，也不按动作数量或文字长度判质量。

以上是语义／画面复核案例，不声称结构验证器能凭关键词判定运镜或演出已成立；结论并入已有director_review。
