# Comic video storyboards Gen2.8.2

## 创作原则

保留全部原漫画镜头及其顺序，台词不增删改。以原作画面作为动作过程中的节点，在节点之间创作完整的动画演出，连续收束到下一节点。人物性格约束表演，漫画格的排版裁切不自动约束动画。规则的唯一维护位置与数据格式见 [core-authoring.md](references/core-authoring.md)。

## 按阶段加载

- 首次读图前完整读取 [core-authoring.md](references/core-authoring.md)。
- 首次人物设计写作前读取 [dialogue-performance.md](references/dialogue-performance.md) 及其链接的表演校准。已有角色设定优先，不从人设图推断性格；新话先读取项目共享人物主档的出场条目，维护方式见 [character-registry.md](references/character-registry.md)。
- 首次导演创作前读取 [director-expansion.md](references/director-expansion.md) 与 [2d-animation-execution.md](references/2d-animation-execution.md) 的通用表现和词汇；战斗部分仅动作段读取。日常、喜剧与情绪戏也可使用二维造型和动态表现。
- 设计或修改摄影机时读取 [cinematic-rendering.md](references/cinematic-rendering.md)。
- 原图身份、肢体、接触、透视不清时读取 [source-risk.md](references/source-risk.md)。新角度本身不触发证据准入。
- 环境、图形背景或配色设计读取 [background-design.md](references/background-design.md)，需要形式库时才读其链接。
- 制作执行提示或处理生成失败时读取 [seedance-execution-and-review.md](references/seedance-execution-and-review.md)。
- 填写或修改台账时按需查 [ledger-v282.md](references/ledger-v282.md)。维护、兼容审计才读 [gen2-5-compatibility.md](references/gen2-5-compatibility.md) 与 [regression-cases.md](references/regression-cases.md)。

各适用模块首次完整读取；明确分出的战斗等条件章节按需读取。此后只查受影响规则，不逐格重载。默认使用一个主对话，不创建写作／审查子对话。沿用一份 V3 台账，不建立分轮事实副本。

正常新作默认使用 [ledger-v282.md](references/ledger-v282.md) 的 compact 写作格式：来源／全文、六字段、表演卡各写一份；状态只写变化，切点差异每个连接只写一次。渲染和校验自动展开，不要求模型读回展开后的全文。脚本直接运行，只有维护或故障定位才读实现；审查只报告结论、问题与受影响范围，不逐镜复述正文。节省辅助记录，不缩减读图、原镜写作或导演创作。

## 总览、两次精读与导演创作

### 总览：保持已经验证的流程

新话或大范围连续创作，先浏览带文件标识的有序分页缩略图，建立场景、段落、环境参考、疑难位置地图。缩略图不证明细节、身份或完整台词，不先做整话转录。局部已批准修订或用户明确跳过时不重做总览。

### 第一次精读：准备资料，观察与初步理解

在当前连续段落内，逐张查看一至三格缓存720p图，记录构图、主体、姿态／表情、持物／接触、环境和全部气泡原文、归属、类型与顺序。按出场查阅人物主档、统一称呼、已有参考与配色，可先起草译文和剧情理解。分开机位、头部朝向、视线，分开图像事实、上下文理解与创作，不从成稿反造证据。

先完成本窗口事实，再做同窗口第二次精读。窗口只是同时看图与记忆管理单位，不限制剧情理解范围，也不是镜头或生成片段边界。必要时查看前后格读通动作；仅关键细节仍不清时放大并记录原因。原格画面是动作中的阶段，不是视频首帧。资料记录不必提前满足最终格式。

含关键动作段时，第一次精读先读完整动作段及必要邻格，按core提交简明动作路径，必须等用户明确确认后再进入该段第二遍写作。总览只标候选位置；不要在尚未读通时请求用户替模型解图。普通无动作段不为此停工。

### 第二次精读：先读通，再完整写好原作镜头

重新逐图打开同一窗口原图，独立检验第一次判断并纠错，不能只读笔记或顺着旧解释补形容词。在同一窗口先理解谁对谁做什么、目标／结果怎样变化、前后格为什么接得上，再写镜头；这不是额外增加一轮看图。动作／混合格按core复核主动作、阶段、空间与运动含义，不能只列身体部位和画面元素。

在同一台账复用story_context简要讲清本段事件与因果，本段首格可承载连贯叙述，不每格重复整段或另建剧情表。逐格明确原作节点、关键状态、机位／构图价值、表情／动作关系及揭晓作用，区分排版裁切与有意遮挡。连续动作原格可以合成一个镜头，各格节点仍逐一落实。

保留已验证的完整写作：原作镜头写六字段、符合角色的局部表演与动画过程、摄影与画幅适配、背景／色彩／布光／声音，并作基本串并行计时；适用P镜仍用已有表演卡和校准，不降为静态骨架或剧情提要。可以保留自然成立的必要覆盖，不强求在本轮完成全部增镜与整场导演设计。主动作理解须落实到正文，不能台账写突进而成稿只写瞪眼持刀。

逐图核准原文、归属、类型、顺序与完整等值译文，冻结来源／全文。核对原作本身的动作空间关系及当前底稿的基本连接。第二遍结束保存实际台账与完整底稿的版本快照，作为第三轮前后的还原对照；不是另起一套持续维护的事实账。完成一场戏或完整动作段后进入第三轮。

本轮只后移最终镜号／邻接差异、跨镜发声的精确切分、最终计时、十五秒分片和执行字数／格式精修。基本时长与临时编号可写，不为暂定组合反复精修；不得以减负为由推迟原镜六字段、原作主动作、明确表情或关键构图的落实。

### 第三轮：继承可靠原镜，创作整场动画演出

进入本轮时先读取 [director-expansion.md](references/director-expansion.md) 开头的创作质量声明，按其中的完整场景导演要求展开；人物演出继续执行 [dialogue-performance.md](references/dialogue-performance.md) 的具体组织与校准审查，不以原镜合规或表演卡齐全代替演出质量。

以第二遍完整底稿为基础，先定人物意图、观众体验、节奏及下一原作节点，再组织原作与自创镜头，设计完整攻防、符合性格的表演、插入与返回、环境／物品、无对白情绪段和停顿。自创过程可以充分设计；原作镜头始终受core的还原门槛约束，不能因进入导演轮而降级。已好的底稿可沿用，不设增镜比例或手势配额。

可调整原镜时长、补充节点前后的表演过程、适配页面裁切，或让真正连续原格构成一个长镜头；经过源节点时仍保留主动作、阶段、主体／持物／接触、关键姿态／表情、观察关系、重要构图与叙事作用。保护的是原作画面内容与表达，不是冻结所有措辞、秒数或逐格停顿。不得删除原作节点或改锁定台词。

扩写原镜时重看对应图，关键动作核对第二遍理解和下一节点；误读回源纠错，不能用来源锁保护错误。缺直接漫画证据只warning，实际违背原作或连续性仍须修正。按core检查新增镜头对最终前后邻镜各至少一项显著差异，并自然到达下一原作节点。

粗排成立后完成新增镜头六字段、所需表演卡、最终秒数与跨镜发声切分，检查所有实际连接，再分生成片段。最终将原镜实现与第二遍底稿对照，原镜有改动处回原图核对；不能只凭文件名／原句仍在或剧情结果相同判定画面已保留。无关且未改动的原镜观察与检查可沿用。

### 最终审查与交付

对最终版本检查原镜画面与表达完整、第二遍到第三遍的原镜保真、对白全文、人物表演、节点到达、邻镜差异、实际连接和时间。增镜只使被替换连接及实际受影响后续失效；原图观察和无关已核镜头不重做。纯编号／算术修订不伪报重新看图。

整段演出成立后再分生成片段，每片默认最多十五秒，用户更低限制优先。不是每格一片，也不以十五秒限制整场戏；不删台词、抹反应、加速发声或填静止尾巴。分段延续实际状态，不重演起手或重置接触。

每个实际切镜独立编号，默认采用精确逐镜模式。六字段依次为【镜头设计】【可见动作】【可见背景】【台词与语气】【光影布光】【声音设计】。字段职责、颜色、首帧、原镜／台词保留、差异门槛、节点到达和 warning 边界只由 core 定义；其余模块引用而不另设门槛。未识别角色在脚本开头集中列出稳定代称与上色提示词；正式六字段不夹带推断、准入或审查解释。不写 BGM。

```powershell
python scripts/build_analysis_proxies.py <panel-folder> --overview
python scripts/freeze_storyboard.py <source-ledger.json>
python scripts/freeze_storyboard.py <source-ledger.json> --review-digest <storyboard.md>
python scripts/validate_storyboard.py <storyboard.md> --max-seconds 15 --image-dir <proxy-folder> --source-ledger <source-ledger.json> --require-source-ledger
python scripts/audit_seedance_prompt.py <execution.md> --max-seconds 15 --max-chars 1900
```

冻结工具在第二次精读核对后锁定来源／对白，只生成一致性指纹，不证明读图或替代人工审查。最终审查后记录实际审查说明和工具打印的版本指纹。报告原镜保留、对白一致性、镜头／新增镜头／片段数、时长、错误、来源 warnings、人工演出结论、实测范围与绝对文件路径；程序零错误不等于动画质量通过。
