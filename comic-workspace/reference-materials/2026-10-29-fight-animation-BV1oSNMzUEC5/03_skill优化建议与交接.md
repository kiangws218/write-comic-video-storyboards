# Skill 优化建议与交接说明

版本：1.0，2026-10-29。对象：把漫画、剧本或动作设想转成二维动画分镜的 skill。

本文件是分析者根据本地视频资料提出的应用方案，不是视频讲解者的逐字原文。与 `01_详细学习资料.md` 和对应 Contact sheet 一起使用。这里没有直接修改已安装的 skill。

## 先读这些，再修改 skill

1. 先读主资料的“来源与证据边界”，再核对 P01-P12 的视频观点和分析者推论。
2. 先看 M01（双速度）、M04（色彩焦点）、M06（延迟结果）、M08（层叠）、M10（镜头入场），再看 A 表扩大上下文。
3. 按当前 skill 的职责选择条款。写分镜的 skill 应输出可见行为、空间、节奏和摄影机关系；不必强迫输出未经测量的原画帧数。
4. 如果用于漫画改编，先保留原作全部必要事件、人物关系、台词和镜头证据，再做动作连接。原作没有的招式、能力、伤害结果、胜负与情节不能借“增强打斗”擅自补入。
5. 优先试改一个完整动作段，再检查效果。不要把12条全部变成每镜头必填、每场必用的硬规则。

## 推荐写进 skill 的核心指令（候选文本）

> 设计动作段落时，先明确人物目的、起止位置、威胁方向与局势变化。围绕一个可读的行动因果组织镜头：起势或意图、移动与发力、接触或未命中、对方反应、余势与下一行动。允许跨镜完成这些阶段；不要把每次击打机械切成五个镜头。
>
> 先写可见的身体动作，再写摄影机和特效。描述支撑与重心、躯干和主发力肢体的先后关系，以及攻击后如何恢复或失衡；画面看不到的身体细节不要伪装成已观察到的事实。
>
> 为每个高强度动作镜头指定一个主要运动方向与一个主要视觉焦点。人物姿态、武器、速度线、拖影和环境反应应支持这一方向；存在反向力时说明它是反击、阻挡、反弹或制造预期的线索。切镜后通过位置、朝向、目标、景物或运动趋势建立接力。
>
> 按叙事目的选择快慢、大小、色彩、几何形和视觉母题。需要快慢对照时，说明谁慢、谁快、慢层让观众读到什么。需要尺度对照时，说明大形体、小参照与角色定位点。需要高密度特效时，保住接触、因果和攻击身份。
>
> 需要延迟呈现时，区分攻击发生与结果可见的时间，并保留能连接二者的路径或接触证据。需要层叠爆发时，安排各层开始、峰值和结束的先后；后一层必须增加新的信息或力量，不以粒子数量代替递进。
>
> 将角色动作与摄影机动作分栏描述。贴近打斗中心、让武器掠镜或让摄影机参与高速转接时，要说明相对位置、跟随对象、空间参照和动作完成后的可读落点。不要用“环绕、抖动、甩镜”掩盖未设计的动作。
>
> 保持运动的有机变化。重复招式保留目的与角色身份，同时根据对手反应、伤势和环境改变节奏、幅度、角度或衔接；不要为了变化让身体、方向或能力失去连续性。
>
> 输出后逐段核查：能否看出谁在对谁做什么；力量如何传到目标；动作造成什么变化；切镜后观众能否接上；特效是否支持而非吞没动作。只使用当前故事和生产条件需要的表现手段。

## 输出字段：按作用选择，不强制填满

| 字段 | 应回答什么 | 依据 | 常见错误 |
|---|---|---|---|
| 段落目标与局势变化 | 谁想达成什么，结束时局势如何改变 | 应用扩展 | 连打三拳但关系和信息不变 |
| 起止空间 | 双方、目标、障碍在何处 | P02/P10/P11 的应用 | 只有景别，没有相对位置 |
| 可见身体动作 | 支撑、重心、转体、肢体接力、余势 | P05/P09 | 身体不动，光束自己完成动作 |
| 主运动方向 | 朝哪儿，谁接收，视线如何走 | P11 | “飞速冲刺”没有目标 |
| 速度分层 | 主体与环境/特效谁快谁慢 | P01 | 整画面一起慢放 |
| 接触与反应 | 命中、阻挡、闪避或落空，如何看出来 | 应用扩展，参考M02/M05 | 用闪白代替接触关系 |
| 尺度与构图 | 大小参照、透视、背景与角色定位 | P02 | 巨大但无从比较 |
| 色彩焦点 | 主色、对抗色、焦点如何保持 | P03 | 所有效果同样亮 |
| 形状与母题 | 能力身份、几何形、跨镜复现与变化 | P04/P06 | 每镜换一套招式造型 |
| 结果时序 | 原因、结果可见点、层叠顺序 | P07/P08 | 爆炸先于可见原因且无解释 |
| 摄影机 | 位置、运动、跟随对象、掠镜物、稳定参照 | P10/P12 | “镜头很燃”无法执行 |
| 剪辑接力 | 动作在哪个阶段切，下一镜如何接 | P01/P11/P12 的应用 | 无缘由换轴或位移跳变 |
| 声音建议 | 哪个阶段需要怎样的声音功能 | 独立创作建议 | 假装视频已证实音画同步规律 |
| 原作证据/新增说明 | 哪些来自原作，哪些是合法连接动作 | 适配漫画任务的约束 | 将新增动作伪装成原作已有 |

## 用同一动作检验改写是否具体

### 模糊版本

“A暴冲，一拳轰向B。镜头疯狂旋转，电光、爆炸、碎石齐飞，慢镜头呈现震撼打击。”

问题：不知道双方的位置和攻击方向；身体如何发力没有被写出；是否命中、接触在哪里、B如何反应全不明确；镜头和特效同时争抢注意力。

### 可执行版本（原创示例，非视频原镜头）

前提：A在画面左侧、B在右侧，平地上相距一个跨步，B身后有石墙。这里只补动作表现，不新增故事结果。

1. 中景侧位。A后脚蹬地，重心前送，髋肩依次转向B；右拳仍留在腰侧，B抬起前臂准备封挡。人物缓慢进入可读姿态，地面尘粒沿左至右掠动，提示持续压力。
2. 延续主方向切到靠近B肩侧的近景。A右拳沿左至右穿入画面，前臂短暂拉出同向尖形拖影；B的防挡臂先迎上，接触位置保留轮廓，接触处小范围变亮。镜头仅沿拳路短移，B肩部保留为参照。
3. 若原作规定B被逼退：转回能看到双方脚位的中景，B肩部先后挫、脚步重新找支撑；尘和墙面反应晚于身体反馈显现。若原作规定挡住：保持B的支撑，改写为肘肩吸收与A拳势被止住，不能擅自加入墙体崩坏。
4. 保留余势。A的前倾与B的恢复决定下一次行动；下一镜从这一未完成的关系接入，不复位重来。

这个例子加入了源视频没有逐项教授的重心/接触/恢复字段，属于应用推导。时长由整场节奏和制作条件决定，不套固定帧数或秒数。

## 验收与失败判据

| 检查 | 通过的可见证据 | 失败时怎么改 |
|---|---|---|
| 意图可读 | 目标和威胁明确，动作改变了局势 | 删除无作用的连招或补目的 |
| 身体可信 | 运动先后、支撑、受力/余势可以从文字执行 | 先重写身体，再加效果 |
| 接触可读 | 观众能分清命中、阻挡、闪避、落空 | 补接触前后关系，减少遮挡 |
| 方向清楚 | 能用一句话说出主方向和下一落点 | 统一姿态、速度线和镜头参照 |
| 速度有层次 | 慢的层承载信息，快的层制造压力 | 调整相对运动，不只改播放速度 |
| 规模有标尺 | 角色、地形、建筑或前后景可比较 | 增加必要的空间参照 |
| 颜色有焦点 | 在缩略图大小也能找到关键人物/接触点 | 降低次级区域强度 |
| 特效有身份 | 几何形、颜色、轨迹与能力保持关联 | 删无关装饰，统一母题 |
| 结果有因果 | 延迟和层叠都能回溯到攻击 | 明确路径、切线或受力位置 |
| 摄影机有任务 | 每次移动都改善可读性、临场感或转接 | 改成更简单的机位方案 |
| 变化有理由 | 重复动作因新条件而调整 | 改动作条件，不加随机抖动 |
| 原作完整 | 台词、事件、角色状态和结果均可回查 | 先恢复原作，再重做演出 |

## 不宜照搬为硬规则的内容

- “每五镜至少一次进入动作场内”：源视频约12:02提出的个人建议，不是普遍制作规范。按段落强度、镜头时长和空间可读性选择。
- “约90%特效几何化”“每帧都全新绘制”“最早/首位系统运用”：是讲解者的概括、修辞或历史判断，没有在本任务中进行统计或独立史料核实。
- “拖影、碎屑全同向”：优先迁移为主方向清楚；反击、对撞、旋转和重力仍有各自物理方向。
- 第十二条中文和英文命名不一致：保留源视频英文标题，工作性区分P10的场内机位与P12的镜头运动/高速转接，不将二次解释写成权威术语。
- 画面来源涉及其他原画师、其他动画和外部分析视频。12条是本教程讲解者的归纳，不能包装成中村丰本人亲授的官方十二法则。

## 给其他对话的可复制任务说明

请先读取这份资料包中的 `00_先读我.md`、`01_详细学习资料.md`、`03_skill优化建议与交接.md` 与 `镜头索引.json`，再打开与修改内容相关的 Contact sheet；不要只读文字概括。以P01-P12作为视频观点索引，以A01-A28作为上下文，以M01-M12作为加密证据。再读取我指定的现有skill，给出“现有问题—视频证据ID与时间码—拟修改条款—预期效果—失败判据”的对应表，并针对一个完整动作段做修改前后对照。

把视频观点、画面观察、你自己的推论分开。保持原skill的任务边界；如果是漫画改编，完整保留原作必要镜头、台词、事件和结果。不要硬塞全部12条，不把0.2x/0.6x教程慢放时长当作原片时长，不虚构命中帧数、作者归属和没有核验的声音规律。经实例验证后再把有效条款整合进skill。
