## 使用约定

- 优先读每份资料的来源、方法与分析边界，区分视频观点、画面观察与应用推论。
- 通过原则ID、时间码、联络表与镜头索引回查，不只摘取结论。
- 图片和PDF使用Git LFS；克隆后运行`git lfs pull`。
- HTML浏览器需下载整个资料目录后本地打开；Markdown可在GitHub阅读。
- 新资料按“日期-主题-来源标识”建立独立目录，并更新本索引。
- 不收录原始视频、重复打包ZIP、OCR缓存或渲染中间文件。
