# 漫画协作工作区

这里存放可供团队领取和制作分镜的漫画素材，以及按话归档的已交付分镜脚本。

## 目录约定

```text
character-references/
  turnarounds/       角色三视图与补充设定图
episodes/
  ep-013/
    source/panels/   已切分的上色单格漫画
    STATUS.md        本话任务状态
  ep-015/
    source/panels/   已切分的上色单格漫画
    storyboards/     按版本和测试范围归档的分镜脚本与审计台账
    STATUS.md        本话任务状态
```

第16、17、18话使用相同的漫画目录结构；有已交付分镜时再建立 `storyboards/`。

## 使用方式

1. 安装 Git LFS。
2. 克隆仓库或切换到包含本工作区的分支。
3. 执行 `git lfs pull` 下载漫画图片。
4. 开始工作前更新对应话数的 `STATUS.md`，记录负责人和状态，避免重复领取。

## 状态约定

- `未分镜`：可以领取。
- `进行中`：已经有人制作，请先与负责人协调。
- `已完成`：分镜已完成；成品脚本后续应放入该话独立的 `storyboards/`，不要混入 `source/`。

## 素材约束

- 当前只上传已切分的上色单格漫画，不上传原始整页或上色整页。
- 人设参考图统一存放在 `character-references/`，不与具体话数的漫画单格混放。
- 所有 `source/` 内容均为源素材，不在原文件上覆盖修改。
- 审核图、总览图、临时缩略图和测试输出不进入本目录。
- 新增分镜脚本时保留漫画原文件名引用，便于审计与复核。
