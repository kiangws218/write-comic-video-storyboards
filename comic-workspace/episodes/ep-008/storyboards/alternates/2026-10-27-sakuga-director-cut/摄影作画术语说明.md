# 第8话｜摄影、作画与特效术语说明

2026-10-28。术语已写入镜内实际字段；本说明用于复核与选词。每个词同时绑定对象、阶段或结果，完整运动仍以正文为准。镜数、时长、日文发声窗口与战斗过程保持。

| 类别 | 已使用术语 | 在本片怎样执行 |
| --- | --- | --- |
| 摄影空间 | 広角パース、金田系透视、multiplane parallax | 强化近拳、近靴与巨兽的深度；近甲快速掠过，远云缓慢移动。 |
| 摄影路径 | tracking shot、orbit tracking、arc tracking、whip pan、camera roll | 分别绑定贴地追逐、绕甲半圈、追头弧线、裂纹到靴底的短甩，以及高空翻身的视轴滚转。 |
| 摄影速度 | speed ramp、ease-out | 清爪及末尾接近按既有窗口常速/慢放切换，顶点上摇先快后慢；日文维持自然发声预算。 |
| 作画姿态 | pose-to-pose、强pose、タメツメ、止め | 蓄势先读清身体紧形，再集中释放；局部持画时发尾与浮石仍延续余动。 |
| 作画过渡 | オバケ／smear frame、squash and stretch、follow-through／overlap | 离甲与冲刺在运动方向短促拉伸，接触姿态恢复清楚；头发与身体错时跟随。 |
| 接触重音 | hit-stop、impact frame、inverted impact frame | hit-stop短留落爪接触形；impact frame瞬时替换黑白画面，末拳作反色剪影，随后读到反作用。 |
| 线与表情 | 剧画脸、line boil、粗线阴影 | 只在反震和狠气表情的重点加强线条密度与短颤，身体方向与脸部识别保持。 |
| 特效与合成 | 手绘エフェクト、块面破片、layered dust、selective glow、contact shadow | 土烟与破片按距离晚到，掌心已有亮点保持局部辉光，齿缝接触影帮助读出压力；赛璐璐分区统一色块。 |
