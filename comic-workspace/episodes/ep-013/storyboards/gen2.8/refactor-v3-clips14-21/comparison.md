# Gen2.8 V3 重构前后对比：第13话片段14—21

## 测试口径

- 基线：`../part2-p016-p031/storyboard.md` 中片段14—21。
- 候选：本目录 `storyboard.md`，按同一批18张720p漫画格重新看图、重新划分片段并重写，未从旧正文做缩写改写。
- 规则输入：重构前常驻读取 `SKILL.md + core-authoring.md + dialogue-performance.md + gen2-5-compatibility.md`；重构后常驻读取仅为 `SKILL.md + core-authoring.md + dialogue-performance.md`，兼容规则改为回归维护时按需加载。
- Token 结果用“常驻规则字符数”作为稳定代理；实际 Token 数受执行模型 tokenizer 影响，不能把字符数冒充精确账单。

## 质量对比

### 1. 同格增镜与片段归属

重构前 `[第13话_25_001.jpg]` 跨越片段14与15，且两个镜头都是相近双人侧向构图。重构后把该格完整收进片段15：

- 分镜1以原格45mm双人中近景承载青的“被撞见→解释卡住”；
- 分镜2不再伪装成第二次原格引用，明确登记为 `uncited_coverage`，改用70mm过肩关系近景和焦点接力承载“春子质问→青立即否认”；
- 三个语义轮次仍完整保留，但按 `解释 / 质问+否认` 两个覆盖组组织，没有机械地一轮一镜，也没有把短问答挤回一个近似镜头。

为了保持15秒硬上限，`[第13话_25_002.jpg]` 被移到片段16；`[第13话_27_001.jpg]` 与无人物的 `[第13话_27_002.jpg]` 共同组成片段17。这样仍保持8个片段和19个分镜，同时修复同格覆盖跨片段的问题。

### 2. 构图与原图一致性

18张图均以720p代理逐张打开确认。候选稿把静态构图集中在【镜头设计】，保留原图的前后景体量、人物左右、裁切、遮挡和视线轴；【可见背景】只写夜空、树冠、灌木、图形底或铺满画面的表面，没有把漫画留白、气泡空间或主体布局写成环境。

多图同镜仅保留在 `[第13话_31_001.jpg]` → `[第13话_31_002.jpg]`，两格确为同一极近景表面沿同一轴线连续发展；镜头设计和可见动作均按“起幅 / 发展”逐条绑定，没有把两格描述堆在一起。

### 3. 人物表演

候选稿把对白镜头扩展为可见因果链，重点增加：

- 眼睛先于头部转动、头眼分离、瞳孔收紧与视线落点；
- 嘴唇开合失败、吞咽、鼻息、呼吸消失与恢复；
- 肩颈绷紧、重心前压、步幅失衡后重新跟齐；
- 白发、背包、衣料和魔物挣动的迟拍与惯性；
- 每镜明确落点，而不是用“抬手指人”或抽象情绪词代替过程。

长对白或高表演风险镜头在V3台账中登记紧凑表演卡、正文摘录与串行/并行估时。`片段15/分镜2` 的日文对白独立估时约8.36秒，因此由原来的6秒修正为9秒；这也是此次总时长增加1秒的主要原因。

### 4. 声音

所有镜头保留环境底声、动作拟音、呼吸/静默、距离/声像与关键同步；没有BGM。声音触发点引用日文原句或“第一句/句末”等通用节点，没有出现“解释时”“质问时”之类中文台词替代。

## 校验结果与警告处置

V3校验结果：8个片段、18张参考图、0个错误、9个审阅警告。

9条警告均已人工复核并保留：

- 片段15分镜2（9秒、双说话人）：8.36秒日文问答需要9秒；过肩构图通过焦点转移承载问答，表演卡覆盖耳尖、视线、摇头、发丝与落点。
- 片段16分镜3（7秒、双说话人）：春子两句说明与魔物尖叫共同依赖夹抱和弹指关系，拆镜会破坏动作因果。
- 片段18分镜1（双说话人）：三句合计约5秒，共享同一画外声源；通过前后景眼神交接区分说话人。
- 片段19分镜3（8秒、双说话人）：青是画外打断，镜头保留在矮人脸上才能读到“恍然→尴尬”的完整反应。
- 片段20分镜2（双说话人）：奔跑中的警告与追问是短促问答，反向侧跟与焦点接力已经提供有效增镜差异。
- 片段21分镜1（两张原图）：两图是同一表面、同一轴线、同一连续动作的起幅与发展，已逐图绑定。

这些是需要人工确认的合理例外，不是未修复的结构错误。

## 总结

本轮测试支持“未劣化”的判断：构图锁定和对白完整性不低于基线，表演链、同格增镜差异、时长真实性和声音同步明显更强；常驻规则输入减少47.6%。代价是V3台账更严格、正文更详细，但台账属于机器审计产物且按1—3格窗口使用，不应整集反复塞入生成上下文。
