## 本轮重点

本测试只验证第一优先级改动：把“剧情理解”与“当前格可生成事实”分开，并对人物、物件、动作及动作目标做来源准入。台词能解释剧情，但不能单独证明画面中出现了某个主体或正在发生某个动作。

两个关键回归点均已纠正：

1. `第13话_5、6、7、8、9_009.jpg` 是纯漫画拟声字格，不再生成独立文字画面；其咀嚼含义只映射到下一张可见进食镜头的【声音设计】。
2. `第13话_12、13、14、15_006.jpg` 只有水下旋流、气泡和水面高光，新稿没有再补出“魔物下沉”。

## 校验结果

使用 Gen2.8 最新校验器、`--require-source-ledger` 和 720p 图目录验证：`0 个错误，3 个人工复核警告`。三个警告均为有意保留的同框短问答或持续表演镜头，不是来源越界、时长超限或漏拆台词。

来源台账不会送入视频模型提示词；它是生成阶段和提交前校验使用的中间审计文件。最终视频输入仍以 `storyboard.md` 中单个片段为单位。
