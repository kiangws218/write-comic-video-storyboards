# 第3话中文字幕

中文取自漫画的中文翻译，经本地 OCR 提取及疑点文字裁片校对；保留原译用词，统一标点和字幕断行。

- `第03话_中文_分镜对齐.srt`：按 `storyboards/current/` 当前稿累计时间；多批稿按原顺序连接，原稿省略的段落不增加画面。
- `第03话_中文_脚本范围NN.srt`：每份当前稿独立从 00:00 开始，适合分批剪辑。
- `第03话_中文_原漫全量含估时.srt`：原漫全量参考时间线。在脚本没有覆盖的原漫位置补入估算时间；后续字幕随新增时长平移。仅适用于包含这些补入段落的完整剪辑。
- 两份 `逐句对照.tsv`：每句起止、时长、时间依据、脚本片段/镜头、漫画来源、OCR 置信度。
- `复核提示.tsv`：短字幕、较快字速和残留 OCR 疑点，供最终配音/剪辑校准。

估时按中文约 4.5 字/秒，加入换气与标点停顿；无对白且无脚本的原漫格默认留 2 秒。分镜对齐版保持原脚本总时长；各句按中文长度分配，较长对白可延续到紧接的无对白画面。全量版还将原译字速超过 8 字/秒的对白窗口按约 4.5 字/秒估时延长，并平移后续字幕；延长均在逐句表中标注，剪辑需同步延长对应画面。日语脚本只作为镜头/顺序索引，不将日语重新翻译成中文。脚本新增但漫画没有印出的喘息、惊叹或改写对白不凭空补写。

未提供成片音频，镜内说话落点为制作预排时间；配音/成片完成后应按实际开口位置微调。原稿改编省略的原文在全量版估时补入，不能直接把全量版套到省略这些段落的分镜成片上。
