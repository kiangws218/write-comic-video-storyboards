# 原图疑难与创作来源风险 — 2.8.2

仅在原图身份、肢体、物件、遮挡／拓扑、快速动作、透视或颜色确有疑难时读取。先 720p，仍影响判断才放大并记录原因。对已批准镜头按 core 的变更范围回看，不重新做全话。

原作观察仍需准确：核对手的主人／左右／数量、连接和接触、前后景、力与运动方向、空中／接地、机位与视线、可见眉眼和物件端点。文字与剧情不是已看见的图像，不能把小黑块随意认成身体再制造轨迹。歧义留在观察中，必要时看邻图／设计参考，不伪报已确认。

人物完整参考图支持正侧背等新机位，不再逐面要求漫画证据。导演可以设计画外身体、未画的房间侧面、路线、接触变化和辅助物品。缺直接证据只在同一台账 creative_additions 中记场景设计假设，可汇总 warning，不阻塞、逐项签批或请求用户许可。不得从“原图没有画”直接推断“这个动作不允许”。core的首次关键路径确认针对原作动作理解，不是为每项导演补充恢复证据准入。

观察事实必须忠实，新增演出必须自洽。若创作导致身份／原句／原镜／结果错误，或无过程换手、瞬移、接触跳变、下一原节点不匹配，修正实际矛盾；不能把证据 warning 当作实际错误，也不能用 warning 豁免真实错误。

原作画面的关系和时间阶段、动画画幅适配、最终前后邻镜各一项差异、节点到达与颜色优先级都由 [core-authoring.md](core-authoring.md) 维护，本模块不另设门槛。源事实不能被生产配色、扩画或推断覆盖。
