# 作画与特效：按标签检索

## 试验样片与短参考处理

[电弧／气流试抠与精简慢放](variants/trial-01/试抠对比与慢放.html)。透明件供合成检查，黑底MP4与对比视频明确标注慢放；不等于恢复原始效果层。

短特效可单独截取并慢放至适用时长，不为凑时混入无关镜头。记录原区间、倍率和输出时长；参考形变时明确慢放，实际生成速度按当前镜头另定。保留原速原片用于节奏核对。

## 引用方式

同一文件可承担多个参考维度，分别写清。例如N05A本次上传为视频1：

> 气浪特效参考视频1前段的白色短喷流；电弧参考视频1后段的游走分叉；命中重音使用视频1后段的黑白冲击帧。

点开片段后选择具体参考维度，复制该维度的引用句。需要哪一层就写哪一层，人物与道具动作由当前镜头独立设计。T01、N05A等是稳定文件编号；“视频1／视频2”只按本次实际上传顺序确定。

“数字‘2999’出场方式参考视频1”属于引用句式示例；具体采用光阵展开等表现时，补上效果维度与动态要求。源中没有2999，数字迁移未做生成测试。
