# 标题叠加素材 · 第一版圆环方案的优化与退场

用途：把「新世界之魔物猎手」标题叠加到已经存在的 OP 镜头上。沿用第一版的圆环展开、字形环绕与汇聚编排，补上呼应圆环的退场。它是一段标题演出素材。

## 时间

- 总长 5 秒，60 fps，共 300 帧。
- 0–1.15 秒：沿用第一版圆环展开与字形沿环排列的思路。
- 1.15–2.55 秒：沿用第一版错时汇聚与轻微回弹，形成完整标题。
- 2.55–3.55 秒：完整标题停留，保留较轻的环线作为呼应。
- 3.55–5 秒：文字回到环上，随圆环一起向中心收拢，完成退场。
- 首尾均为全透明帧。

保留定稿字形和弧形英文，以白色描边提高在镜头上的可读性。圆环、中心星形和字形轨道继承第一版的运动语言；去掉独立片头式的实底、穿梭场景和附加口号，让它适合叠加到原 OP。素材不带音轨，便于使用原 OP 音乐。

## 剪辑用文件

| 文件 | 内容 |
| --- | --- |
| `exports/Title-overlay-4K60-alpha.mov` | 3840 × 2160，ProRes 4444，含透明通道 |
| `exports/Title-overlay-1080p60-alpha.mov` | 1920 × 1080，ProRes 4444，含透明通道 |
| `exports/title-overlay-png-4K60/0000.png` 至 `0299.png` | 4K 透明 PNG 序列，以 60 fps 导入 |
| `exports/Title-overlay-hold-4K.png` | 静止的完整透明标题，可用来延长停留 |
| `exports/Title-overlay-preview-1080p60.mp4` | 仅用于观看动作的灰格预览，不包含透明通道 |
| `title-overlay.html` | 可切换灰格、深色、白色底的实时预览 |

把透明 MOV 放在原 OP 视频上方一条轨道即可。灰格只存在于预览 MP4 和预览界面，不在透明 MOV 或 PNG 中。停留需要更长时，可以在标题完全出现后插入静止透明 PNG，保留入场与离场段。

已检查两个 MOV 的实际帧数、解码，以及首帧、停留帧、尾帧的 Alpha 通道。结果保存在 `qa/title-overlay-verification.json`。

圆环版本替代此前过度简化的纯文字版本。它直接复用第一版的 `prologue`、`orbit`、`assemble` 运动编排，再补上回环收拢退场；两段中插继续使用已经修正为弧线飞入的版本。此前版本保留在历史文件及 `revisions/` 下。
