## 风格及工程

纯白 `#FFFFFF`、皇家蓝 `#216AE1`、天蓝 `#25A9E4`、深蓝 `#173B80`。SVG / Canvas 代码绘制；定稿的中文标题字形及符号关系作为统一标识，情报正文保持清晰可读。

各目录留存绘制代码、字形路径与布局参数。构建脚本中的依赖路径对应原制作电脑，其他电脑需调整 Node.js / Sharp / Playwright 路径；预览 HTML、PNG、SVG 和成片可直接使用。视频采用固定时间逐帧导出，避免实时录制停帧。

视频和 PNG 使用 Git LFS；下载仓库后执行 `git lfs pull` 获取完整素材。`delivery-manifest.json` 留存源成果的逐文件 SHA-256 校验值。历史版本的完整归档继续保存在本地平面素材目录。
