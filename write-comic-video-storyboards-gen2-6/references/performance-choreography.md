# 二次元人物表演编排

本参考用于把源图中可见的姿态、关系和对白编排成连续的二维动画表演。它负责“怎么活起来”，不负责发明“发生了什么”。`source-grounding.md` 的证据顺序、阶段锁定和镜头权限始终优先；本文件的任何增强都不能新增人物、道具、接触、路线、事件、结果、隐藏动机或超出画面权限的动作。

## 核心原则

- **表演是因果链，不是手势清单。** 先确定源图允许的刺激或说话节点，再写人物如何注意到它、身体如何逐层反应，以及最后停在哪里。
- **先恢复源图，再加表演。** `source_locked` 镜头必须在指定阶段保留构图、姿态、视线、手/道具、接触、重叠和背景层级；增强只改变时间中的细微变化。
- **一个镜头可以有很多微动作。** 三秒不是动作数量上限；上限是因果一致性。一个主意图可容纳连续的视线、眼睑、嘴角、呼吸、手指、重心和衣发延迟，但不能塞入多个无关行为或未经证据支持的剧情结果。
- **局部、不对称、带惯性的变化更自然。** 面部不必整齐同步，手势不必对称，人物停下后发丝、衣摆、饰物或手中物件也不必同时冻结。
- **动作来自任务和关系。** 优先使用角色正在持有、触碰、避让、整理或依赖的可见对象，以及当前对白对象；不要用通用动作替代具体反应。

## 表演编排顺序

写正式分镜前，在内部完成以下最小表演卡；无需把字段原样输出给用户：

```text
源图允许的初始状态：姿态、重心、视线、可见手/道具、接触、表情
刺激/语义节点：看见、听见、被触碰、对白中的词、动作结果或环境变化
表演意图：人物此刻要注意、掩饰、靠近、退缩、确认或维持什么
第一反应：注意力先落在哪个可见部位
视线轨迹：停留 → 偏移/回看 → 结束注视点
面部层：眼睑/眉梢 → 瞳孔方向 → 嘴唇/嘴角
呼吸层：吸气、停息、吐气、吞咽或呼吸恢复（仅在可见/可听依据成立时）
手部/道具层：已有手、抓握、压力、整理、松开或接触变化
重心层：足底、膝、髋、肩、头的先后关系
延迟层：发丝、衣料、饰物、包带、液体或蒸汽的跟随与回弹
结束状态：稳定姿态、最终视线、手部关系、表情余韵和可交接的下一状态
```

如果无法写出“刺激”或“结束状态”，不要用夸张手势填空；保留源图的中性状态，或改用有证据的反应镜头。

## 刺激到收束的表演链

按需要选取下列阶段，不要求每一镜都全部出现：

1. **初始保持。** 先明确人物已经在做什么，保持重心、持物和屏幕位置，不要无故重置姿态。
2. **注意捕获。** 声音或视觉刺激先改变眼睛、耳侧头部或呼吸，而不是立即转身或举手。可用短暂停顿、眼睑微抬、视线停住、下巴轻收等可读变化。
3. **识别与评估。** 让视线沿着对象或说话者移动；眉梢、眼皮、瞳孔方向或嘴唇张合只发生局部变化。惊讶、迟疑、确认和掩饰应有不同的先后顺序。
4. **意图显露。** 用一个与任务有关的手指压力、握法调整、肩颈放松/收紧、躯干微倾或重心转移表达反应。手的变化应有可见对象或身体关系作为支点。
5. **语义同步。** 让开口、吸气、重音、停顿与表演节点相遇；不要让所有动作在台词开始前一次性完成。
6. **余波与收束。** 说完或动作完成后保留短暂的视线、呼吸、手指压力或衣发回弹，落在一个明确、可交接的结束状态。

可压缩为：`刺激 → 注意停顿 → 视线/头部 → 眉眼/嘴部 → 呼吸/手部 → 重心与延迟运动 → 稳定`。在快节奏动作中可跳过中间层，但必须保留方向、接触和结果的因果关系。

## 微表情与微动作语法

### 眼睛和脸部

优先写轨迹与先后，不要只写情绪名：

- 视线先停在原目标，随后偏向说话者，再短暂回看原目标；
- 眼睑先垂下，瞳孔稍后移动；或瞳孔先锁定，眉梢随后松开；
- 一侧眉梢轻挑、另一侧保持；嘴角只向一侧牵动；一边脸放松而另一边仍有张力；
- 嘴唇轻启、抿住、吞回未说完的气，或在句末才形成浅笑；不要默认张大嘴、整齐睁眼；
- 下巴、颈侧和肩膀的方向可以与目光略有延迟，避免“眼、头、身体同时机械转向”。

每个变化都应服务于当前可见意图。源图只支持中性表情时，不要擅自补泪、愤怒、羞怯、压抑等内心状态；强情绪至少需要对话、面部/身体表现、相邻情境中的两类证据。

### 头部与面部朝向

头部转动和脸面朝向必须写成可生成的空间变化，不能只写“看向某人”：

- 起始状态至少在需要时明确正面、三分之二侧面、侧脸、背面回头，俯仰角度，以及脸朝画面左/右或镜头内外；
- 眼睛可以先于头部移动，随后下巴、鼻尖、脸部中线、耳侧轮廓依次改变；头部再带动颈侧、肩线和发束，避免眼、脸、头、躯干同时转完；
- 小幅反应优先写`瞳孔先向画面左侧偏移 → 下巴轻收 → 脸从正面转成三分之二侧面 → 肩线保持`一类可见轨迹；大幅转头需写清支撑轴、转动方向和结束朝向；
- 区分“目光方向”和“脸部方向”。角色可以脸朝前而眼睛侧看，也可以先回眼、再回脸；不要把视线变化误写成整个头部转动；
- 俯视、仰视、低头、抬头分别通过下巴、鼻底/额头可见量、眼睑开合与颈部受力体现；不要只贴情绪标签；
- 结束状态必须给出最终脸面朝向、注视点和头肩关系，使独立生成的片段拥有完整落幅。

源图看不见完整头部或角度证据不足时，只描述可见的眼睑、嘴部、下巴边缘或局部转动，不补造完整转头。

### 呼吸、吞咽与压力

呼吸是时间和情绪的连接器，不是每镜必加：

- 句前短吸气，重音前稍停，句末吐气并让肩颈回落；
- 紧张时呼吸变浅、吞咽后才继续说，放松时吐气带动胸肩回落；
- 手指压力通过指尖、指节、掌根和握持物的微变形可见；先收紧，后在台词或结果落定时松开；
- 不把“呼吸、吞咽、眨眼、手指收紧”写成互不相关的排队动作；可让其中一项处于持续状态，另一项在语义节点发生。

只有在画面尺度、动作声或对白节奏允许时才写吞咽、胸腔起伏等细节。不可见、不可听、会改变角色身体结构的生理反应不得加入。

### 身体重心

用重心变化替代尴尬的说明性手势：

- 足底先稳住，膝盖或髋部随后吸收停步的惯性；
- 躯干微倾后，肩膀和下巴再跟随；
- 转向时先释放支撑脚，再让髋、肩、头依次追上视线；
- 犹豫可表现为重心停在两脚之间、上身欲前而肩膀收回；确认可表现为支撑脚稳住、肩颈放松；
- 坐、起、俯身、提物等动作必须保留源图可见的支点和接触，不补画外撑地、换手或新路线。

重心变化应让脚、膝、髋、肩、头在时间上有轻微错位；避免“整个人像一张纸同时平移”。

## 道具和环境交互

可见道具是最可靠的自然表演支点。只使用源图中存在且镜头权限允许的对象：

- 握持物：指尖压力、拇指位置、握法微调、提带回弹、重量让肩膀略沉；
- 衣物/包带：整理门襟、压住被风带起的衣角、包带滑动后由现有肩部顶回；
- 桌面/托盘/门框等支面：掌根轻触、指节抵住、重心借力后回正；
- 可见介质：发丝、衣料、蒸汽、树叶、雨水或尘粒随动作和既有风向延迟运动。

不要为了让角色“有事做”新增道具、第二只手、隐藏接触、可见之外的物理结果。道具交互必须保留原有手、握点、接触和屏幕关系；若改变这些关系，应另列有证据的 `source_supported_phase`，不能藏在表演形容词里。

## 三秒镜头的密集表演

三秒内可以写多层微动作，采用“同一刺激、分层反应、一个落点”：

```text
0.0–0.5：保持源图姿态；听见/看见刺激，视线先停住，吸气被截断。
0.5–1.2：一侧眼睑和眉梢先变化，头部只跟半拍；对白进入。
1.2–2.2：视线移向对象，嘴唇随重音变化；已有手指在可见道具上收紧，重心微调。
2.2–3.0：吐气、眉眼松开或保留余波；衣发/饰物延迟回弹，落到明确结束姿态。
```

上述时间只是编排参考，不能强行套用。可将多个微动作并发或重叠；只有会改变镜头焦点、构图、接触或剧情结果的行为才需要新镜头。三秒内禁止连续安排互不相关的“转身→挥手→跑开”等完整行为，除非源图阶段和相邻面板明确支持整个链条。

## 对白同步

- 先按自然语速确定对白时长，再决定动作与镜头时长，不为填满三秒而加动作。
- 每句台词至少有一个语义触发点和一个有意义的可见表演变化；短句可用视线/嘴角/手指中的一至两项，长句用阶段性变化或真实切镜承载。
- 反应可与说话并发：吸气在开口前，视线在关键词时移动，手指压力在重音或迟疑处改变，句末以呼气或表情余韵收束。
- 说话者与听者都只能使用源图支持的可见部位和关系。画外说话可引出支持的目光、手部、道具或环境反应，但不可借声音制造新人物或新事件。
- 需要在视觉提示词中引用台词触发点时，使用该镜头实际说出的日文原句片段并置于 `「」` 内；音频细节另写在声音设计行。

## 四至六秒对白的可见发展

四至六秒不是把一个表情拉长。先把台词划成开口、信息/重音、转折、句末四类语义节点，再从源图允许的内容中安排持续发展：

- 起始0.5–1秒：自足地交代姿态、脸面朝向、注视点和手/道具关系；刺激进入时先出现注意停顿；
- 台词前半：眼睛与头部朝向产生一次有因果的变化，面部至少一个局部发生非同步变化；
- 台词中段或重音：手/道具压力、肩颈、重心或与环境接触中的一项发展，听者可延迟半拍响应；
- 台词后半：焦点、景深或极克制的镜头运动可以强化注意转移，但不能替代表演；
- 句末0.5–1秒：呼吸、手指压力、头肩或衣发惯性完成余波，落到明确结束朝向和姿态。

这些层可并发，不要求机械占满每个时间格。若当前构图无法提供至少两个有意义的发展节点，应拆成说话者、听者、手/道具或环境反应等真正不同的编号分镜，而不是把静态构图硬撑到六秒。

## 手势多样性与抑制

抬手指人、摊手、点头、抱臂、握拳、突然睁大眼不是禁用动作，但不能成为默认模板。每次使用前回答：它是否由当前对白、对象、道具、关系或空间阻力直接导致？若不能，替换为更小且更具体的反应：

| 机械手势 | 优先尝试的具体反应 |
|---|---|
| 抬手指人 | 视线先锁定，指尖在身侧收紧，或只用下巴/肩线微调方向 |
| 摊手解释 | 手掌贴近已有物件，拇指调整握法，呼气后肩膀回落 |
| 连续点头 | 眼睑先垂下，重心向支撑脚沉，句末才一次轻微确认 |
| 抱臂防御 | 肘部靠近身体、手指捏住衣缘或已有带子，肩颈逐渐收紧 |
| 突然握拳 | 指节从放松到局部收紧，再在结果落定后松开 |

相邻镜头避免重复同一套手势、同一侧眉眼变化和同一条视线轨迹。重复必须有意表达状态未变，并在措辞中保留新的语义或物理原因。

## 延迟运动与二维动画质感

在主体动作之外，选择零至数个已有次级元素做跟随，不把它们写成独立剧情：

- 主体停步后，发梢、衣摆、辫子、饰物或包带晚半拍摆动并回落；
- 肩膀转回时衣料褶皱先受力，手松开后布料再恢复；
- 物件受握压或释放时只出现与材质相称的微小回弹；
- 风、蒸汽、落花、尘粒或树叶遵循画面已有方向，不能用来遮盖源图锚点。

延迟运动的速度、方向和幅度要服从主动作、既有环境力和材质。不要在每镜堆叠头发、粒子、炫光等效果；表演不应依赖装饰性特效才能成立。

## 多人物反应

先确定当前镜头的主表演者和注意焦点。其他可见人物只作源图支持的监听反应：

- 目光接收或回避、眉眼轻变、呼吸/姿态保持、手与已有物件关系改变；
- 主表演者的动作先发生，监听者可延迟半拍反应；不要让所有人同时点头、转头或张嘴；
- 保持人物之间原有左右、前后、遮挡和视线轴。新增反应不能制造未见的交流对象、接触或事件。

## 输出前审计

逐镜检查：

1. 当前源图的初始姿态、手/道具、接触、背景和镜头权限是否仍可辨认？
2. 表演是否有明确的源图支持刺激或对白节点，而不是凭空解释内心？
3. 是否能用一句话说清 `刺激 → 反应 → 结束状态`？
4. 眼神、面部、呼吸、手部、重心和延迟运动是否按因果先后发生，而非同时机械触发？
5. 三秒内的多个微动作是否服务同一意图；是否误写成多个完整剧情行为？
6. 手势是否来自可见任务、道具、关系或空间；是否与相邻镜头重复？
7. 对白、重音、停顿和反应是否自然重叠；是否为了填时长而加动作？
8. 是否新增人物、道具、接触、路线、隐藏动作、情绪事实或结果？若是，删除或改为有证据的阶段/镜头。
9. 结束状态是否稳定、可读，并能与下一源图阶段连续？

若画面仍僵硬，优先补充受支持的视线轨迹、呼吸停顿、局部面部变化、道具压力、重心错位和延迟运动；不要用更大的手势、更多镜头或新的剧情来掩盖缺乏因果链。
