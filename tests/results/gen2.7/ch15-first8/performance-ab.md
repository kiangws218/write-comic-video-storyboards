# ch15_p07_c001 表演保真 A/B

## 结论

旧 Gen2.7 在这格确实把高密度表演压成了动作摘要。修订稿恢复了 Gen2.6 cinematic 的节拍密度，但没有复制其中与源图冲突或证据不足的内容。

## 保留并加强

- 手/肩/头/发袖形成连续受力链，而非并列手势。
- 两次 `いりません` 分成不同的身体与声音节点。
- 眼睑、泪珠、嘴型、肩线、双掌和喘息共同承载情绪。
- 摄影机从面部转到交接关系，并在具体位置落幅。
- 第二分镜从晶石下滑、托底警告到抱怨重音形成独立、可冷启动的完整动作链。

## 未从 Gen2.6 恢复

- `不是一次性甩开`：负面比较式控制，改为正向分阶段动作。
- `视线在石头、矮人脸和出口方向之间折返`：源图中青双眼紧闭，且没有出口证据。
- `拇指避开她的指节`：证据不足且不改变核心表演关系。
- 通用尾句“最后让当前视线或手指停住，身体重心落定”：改为本镜具体终态。
- 无动机炫光：源图没有强光轴依据，改用泪珠和晶石的局部冷白高光。

## 验收槽

| 槽位 | 修订稿证据 |
|---|---|
| 自足开场 | 闭眼含泪、双掌在胸前、矮人侧脸与晶石交接关系 |
| 语义节点1 | 第一声拒绝时手腕推出，肩线随后内缩 |
| 语义节点2 | 第二声前嘴唇合拢换气，再张口并摇头 |
| 局部面部 | 眼睑压力、泪珠、嘴唇闭合→张开→半开急喘 |
| 耦合/延迟 | 长发和袖口晚半拍反向甩开并回弹 |
| 道具/接触 | 晶石始终处于双掌与承托手围成的交接区 |
| 镜头落幅 | 句末稳定在人物面部与交接区的三角关系 |
| 声音分拍 | 第一声回响；第二声随肩线收干；结尾留下回弹、轻碰与喘息 |

## 剩余验证

脚本层已通过。仍需使用同模型参数实跑旧 Gen2.7 与修订稿，重点观察：嘴型换气是否自然、摇头与长发回弹是否错拍、双掌/晶石接触是否稳定、镜头是否在句末真正落稳。
