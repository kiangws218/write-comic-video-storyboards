# Gen2.8.2 实施与验证

发布日期：2026-10-22。版本保持 **2.8.2**，独立标识为 `write-comic-video-storyboards-gen2-8-2`。继承本地2.8.1已验证的总览、两次实际精读、完整原镜写作和表演校准材料。程序回归通过，版本状态仍为测试中；没有宣称本次完成动态分镜或成片质量验证。

## 本次落实

- 总览保持场景地图；第一次精读整理图像事实、原文与理解。关键动作段先向用户展示简明路径，获得明确确认后再开始该段第二次精读写作。路径须区分世界运动、相对摄影机运动与导演拟补过程；已给出的明确解释可引用，不把泛泛“继续”当作新路径确认。
- 第二次精读重新逐图读通“谁对谁做什么”，完整写原镜六字段、局部角色表演和基本串并行计时。动作含义落实到正文；不把第二遍降为静态清单，也不把原作还原责任移交导演轮。
- 第三轮以整场动画导演思路设计动作、表演、监听反应、物品／环境插入、无对白情绪段、停顿与节奏。可调整时长、设计完整过程；下一原作节点必须自然到达。已确认关键路线内的创作无需逐镜申请许可。
- 所有原格画面节点及顺序保留，台词全文不增删改；完整等值译文在第二遍核准后锁定。实际纠错回源、保留旧锁与原因。连续相近原格可合成一个长镜头，逐格映射阶段和状态；不同反打、揭示或时间不能随意合并。
- 漫画格尺寸导致的裁切不强迫动画照搬；保留有意遮挡、揭示及原镜的叙事价值。完整人物参考支持新角度，缺直接漫画证据只warning；实际矛盾仍报错。
- 新增镜头与最终实际前后邻镜分别至少有一项显著差异。A→B→A可成立；实际相邻新增镜头也各自受约束。程序核对邻接和正文，显著性仍由导演判断。
- 项目共用人物主档维护性格：春子三无克制、青活泼阳光、董白高傲自负；结合当下情境演出。未识别角色用稳定ID和统一称呼，脚本开头集中输出上色提示词。
- 业界分镜、表演、摄影和动作资料已落实于director、dialogue、cinematic等模块，含资料链接；保护原节点，同时给动画过程、观众注意力、动作预备／响应、节奏和角色反应留出创作空间。

## 辅助记录减量

默认 `compact-2.8.2` 创作台账。来源与对白存一处，六字段只创作一份，程序渲染成稿；状态仅填写起始值及各镜变化，每个实际切点的差异只登记一次，P表演卡内联镜头，不重复target。工具展开为既有检查格式，无需模型阅读展开全文。复杂摄影才另留简短决策记录，常规摄影直接维护实际镜头字段。

保留两次真实精读、完整六字段和实际表演计划；不为省token压缩创作。适用模块首次按阶段读取，后续仅查受影响段落；工具直接执行，维护才读实现。最终审查写实际结论与问题，不再复制逐镜正文。派生文件和第二遍只读快照不成为另一套维护台账。缺证据warning可汇总，不逐项消警签批。

两个现有样例做存储转换核对，来源／对白锁、六字段、时长、状态、表演卡及渲染正文均保持一致。格式变化使原最终审查指纹失效，测试没有自动补审查通过。详情见[精简格式核对](compact-check.json)。这是UTF-8序列化字节测量，不是token实测或成本承诺。

## 冲突与冗余审查

| 问题 | 处理 |
| --- | --- |
| 兼容说明遗留“每格独立成镜”，与连续原格合镜冲突 | 改为全部节点保留，符合条件时合镜并逐格实现；core唯一维护规则。 |
| 证据不足只warning，是否还需关键路径确认 | 证据warning针对导演补充；确认针对首次关键原作动作理解，不恢复逐项创作准入。 |
| 第二遍减负可能把原镜还原责任全部后移 | 第二遍保留完整原镜写作、主动作和基本计时；最终邻接、切分及分片由第三轮落实。 |
| 强制每镜另写摄影计划、双侧差异和完整状态 | 正文摄影单一维护；每切点一次差异；状态增量机械展开。显著差异、表演和连续性要求不减弱。 |
| 最终检查被误当每次修改后重审全话 | 绑定实际版本，只重查受影响内容，保留未受影响的观察和审查；程序不代签通过。 |
