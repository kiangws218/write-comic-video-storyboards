# 动画图形背景：经看图核实的形式库

按需读取：已决定考虑图形底场，或需要区分、选取其形式时使用。实景连续性和四种背景模式由 `core-authoring.md` 定义；选择流程、动态证据和字段边界由 [background-design.md](background-design.md) 说明。本库不增加准入门槛、效果配额或新的校验字段。

下列是实际动画静帧的可见形式，不是已经核实的动画运动。用途栏是改编时的可选判断，不是原作剧情解释，也不是“某种情绪必须配某种背景”的规则。不要复制角色、字幕、道具、眼部图案、Q版变形或原图的完整构图。正式六字段不写来源和解释。

## 从形式到制作描述

在既有 `background_decision.basis` 中简记选择理由、参考和必要改编；这些证据不写进正式稿。先决定需要什么作用，再借鉴一种适合本段的形式或协调的组合。它不是必选菜单，也不限制在已列出的题材；新的复杂图案仍按背景模块的研究流程核实。

静态图形可以直接使用。若设计动态，用于支持既有表演拍点：例如选定圆斑层做低幅度明暗变化、选定强调线层在既有反应点出现后收住。这里的动法是制作选项，**不是这些静帧原作的已观测运动**；不规定每镜必须动、持续时间或转场样式。若要声称“原动画就是这样流动/闪烁”，另需实际查看视频/GIF并记录时间范围。

正式背景描述应只保留可执行画面，如：`近白底场上，浅黄与橙色圆点错列铺开，大小一致，留出较宽的白色间隔。` 不加入“参考某作品”“表示可爱”“已核实”等说明；不借背景字数挤掉人物表演。
